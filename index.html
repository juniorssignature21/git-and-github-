Part 1: Installing Git

For Windows Users

Step 1: Go to the Git website

  • Open your web browser
  • Type: git-scm.com
  • Press Enter

Step 2: Download Git

  • Click the big "Download for Windows" button
  • Wait for the download to complete (it's about 50MB)

Step 3: Install Git

  • Find the downloaded file (usually in your Downloads folder)
  • Double-click the file named something like Git-2.43.0-64-bit.exe
  • Click "Next" through all the screens (the default options are fine)
  • Click "Install"
  • Wait for installation to complete
  • Click "Finish"

Step 4: Verify Git is installed

  • Press the Windows key on your keyboard
  • Type: cmd (this opens Command Prompt)
  • Press Enter
  • In the black window that appears, type: git --version
  • Press Enter
  • You should see something like: git version 2.43.0
Success! Git is now installed on your Windows computer.

For Mac Users

Step 1: Check if Git is already installed

  • Press Command + Space to open Spotlight
  • Type: terminal
  • Press Enter
  • In the Terminal window, type: git --version
  • Press Enter

If you see a version number, Git is already installed! Skip to Part 2.

Step 2: Install Git (if not already installed)

Option A - Easiest Method:

  • When you typed git --version, a popup might appear asking to install developer tools
  • Click "Install"
  • Wait for installation (this might take 10-15 minutes)

Option B - Using Homebrew:

  • First, install Homebrew by going to brew.sh
  • Copy the command shown on the website
  • Paste it in Terminal and press Enter
  • After Homebrew installs, type: brew install git
  • Press Enter

Step 3: Verify installation

  • Type: git --version
  • Press Enter
  • You should see: git version 2.43.0 (or similar)
Success! Git is now installed on your Mac.

For Linux Users (Ubuntu/Debian)

Step 1: Open Terminal

  • Press Ctrl + Alt + T

Step 2: Update package list

  • Type: sudo apt-get update
  • Press Enter
  • Enter your password when asked

Step 3: Install Git

  • Type: sudo apt-get install git
  • Press Enter
  • Type Y when asked to confirm
  • Wait for installation

Step 4: Verify installation

  • Type: git --version
  • Press Enter
  • You should see: git version 2.43.0 (or similar)
Success! Git is now installed on your Linux computer.

Part 2: Setting Up Git

Now that Git is installed, you need to tell Git who you are.

Step 1: Open your terminal/command prompt

  • Windows: Press Windows key, type cmd, press Enter
  • Mac: Press Command + Space, type terminal, press Enter
  • Linux: Press Ctrl + Alt + T

Step 2: Set your name

Type this command (replace "Your Name" with your actual name):

git config --global user.name "Your Name"

Press Enter

Example:

git config --global user.name "John Smith"

Step 3: Set your email

Type this command (replace the email with your actual email):

git config --global user.email "your.email@example.com"

Press Enter

Example:

git config --global user.email "john.smith@gmail.com"

Step 4: Verify your settings

Type:

git config --list

Press Enter

You should see your name and email in the output.

Success! Git now knows who you are.

Part 3: Creating a GitHub Account

GitHub is a website where you can store your code online and share it with others.

Step 1: Go to GitHub

  • Open your web browser
  • Type: github.com
  • Press Enter

Step 2: Sign up

  • Click the "Sign up" button (top right corner)
  • Enter a username (this will be part of your profile URL)
    • Example: johnsmith123
    • Your profile will be: github.com/johnsmith123
  • Enter your email address
  • Create a password (make it strong!)
  • Click "Continue"

Step 3: Verify your account

  • GitHub will ask you to solve a puzzle (to prove you're human)
  • Complete the puzzle
  • Click "Create account"

Step 4: Check your email

  • Open your email inbox
  • Find the email from GitHub
  • Click the verification link or enter the code shown

Step 5: Answer the welcome questions

  • GitHub will ask a few questions about how you plan to use it
  • You can skip these or answer them (it's optional)
  • Click "Continue" or "Skip"
Success! You now have a GitHub account.

Part 4: Creating a New Repository on GitHub

A repository (or "repo") is like a folder for your project. It holds all your files and tracks changes.

Step 1: Log in to GitHub

  • Go to github.com
  • Click "Sign in" if you're not already logged in

Step 2: Create a new repository

  • Look for a "+" symbol in the top right corner
  • Click it
  • Select "New repository"

Step 3: Fill in repository details

Repository name:

  • Type a name for your project (no spaces!)
  • Example: my-first-project or hello-world

Description (optional):

  • Type a short description
  • Example: "My first GitHub repository"

Public or Private:

  • Public: Anyone can see your code (choose this for learning)
  • Private: Only you can see your code
  • For now, choose Public

Initialize this repository with:

  • ✓ Check "Add a README file"
    • A README is a file that describes your project
    • This makes it easier to get started

Add .gitignore:

  • Leave this as "None" for now
  • (This is for ignoring certain files, we'll learn this later)

Choose a license:

  • Leave this as "None" for now
  • (Licenses tell others how they can use your code)

Step 4: Create the repository

  • Click the green "Create repository" button at the bottom
Success! You've created your first GitHub repository! 🎉

You'll now see your repository page with a README.md file.

Part 4B: Creating a Local Project and Pushing to GitHub

Now let's learn how to create a project on your computer and upload (push) it to GitHub.

Creating a Local Project Folder

Step 1: Create a project folder on your computer

Open your terminal/command prompt and navigate to where you want to create your project:

Windows:

cd Documents

Mac/Linux:

cd ~/Documents

Now create a new folder:

mkdir my-local-project

(mkdir means "make directory" - it creates a new folder)

Go into the folder:

cd my-local-project

Step 2: Create some files in your project

Let's create a simple HTML file. Type this command:

Windows (Command Prompt):

echo <!DOCTYPE html> > index.html
echo <html> >> index.html
echo <body> >> index.html
echo <h1>Hello World!</h1> >> index.html
echo </body> >> index.html
echo </html> >> index.html

Mac/Linux:

cat > index.html <<EOF
<!DOCTYPE html>
<html>
<body>
    <h1>Hello World!</h1>
    <p>This is my first project!</p>
</body>
</html>
EOF

Or you can simply open a text editor and create the file manually!

Let's also create a README file:

Windows:

echo # My Local Project > README.md
echo This is my first local project that I'm pushing to GitHub. >> README.md

Mac/Linux:

echo "# My Local Project" > README.md
echo "This is my first local project that I'm pushing to GitHub." >> README.md

Step 3: Verify your files were created

ls

(or dir on Windows)

You should see:

  • index.html
  • README.md

Turning Your Folder into a Git Repository

Step 4: Initialize Git in your project folder

Make sure you're inside your project folder (my-local-project), then type: 

git init

Press Enter

You should see: Initialized empty Git repository in ...

This creates a hidden .git folder that Git uses to track your changes.

Step 5: Check the status

git status

This shows you which files Git sees. You should see your files listed in red under "Untracked files".

Step 6: Add files to Git (staging)

Tell Git which files you want to track:

git add .

The dot (.) means "add all files in this folder"

Or you can add files individually:

git add index.html
git add README.md

Step 7: Check status again

git status

Now your files should be listed in green under "Changes to be committed".

Step 8: Commit your files (save snapshot)

A commit is like saving a snapshot of your project:

git commit -m "Initial commit - added index.html and README"

The -m means "message" - always write a short description of what you did.

You should see output confirming the commit was successful.

Creating a Repository on GitHub (for your local project)

Step 9: Create a new repository on GitHub

  • Go to github.com
  • Click the "+" symbol in top right
  • Select "New repository"
  • Name it: my-local-project (same as your folder name)
  • Add description: "My first local project"
  • Choose Public
  • IMPORTANT: Do NOT check "Add a README file" (we already have one!)
  • Click "Create repository"

Step 10: Copy the repository URL

After creating the repository, GitHub will show you a page with instructions. You'll see a URL like:

https://github.com/yourusername/my-local-project.git

Copy this URL!

Connecting Your Local Project to GitHub

Step 11: Link your local folder to GitHub

Back in your terminal (make sure you're still in the my-local-project folder), type: 

git remote add origin https://github.com/yourusername/my-local-project.git

(Replace yourusername with your actual GitHub username and paste your URL)

This tells Git: "The online version of this project is on GitHub at this URL"

Step 12: Verify the connection

git remote -v

You should see your GitHub URL listed twice (for fetching and pushing).

Step 13: Push (upload) your code to GitHub

git push -u origin main

Or if it asks you to use master instead:

git push -u origin master

What this means:

  • git push = upload your code
  • -u = remember this connection for next time
  • origin = the GitHub remote we just added
  • main = the branch name

If GitHub asks for username and password:

  • Enter your GitHub username
  • For password, you need a Personal Access Token (not your regular password)
  • Go to GitHub → Settings → Developer settings → Personal access tokens → Generate new token
  • Or use GitHub Desktop app to avoid this step

Step 14: Check GitHub to see your files

  • Go back to your browser
  • Refresh your repository page on GitHub
  • You should now see your index.html and README.md files!
Success! You've created a local project and pushed it to GitHub! 🎉

Making Changes and Pushing Again

Now that your project is connected to GitHub, here's how to update it when you make changes:

Step 1: Make a change to your file

Open index.html in a text editor and add a new line:

<p>I just learned how to use Git and GitHub!</p>

Save the file.

Step 2: Check what changed

git status

Git will show you that index.html was modified.

Step 3: Add the changes

git add index.html

Or add all changed files:

git add .

Step 4: Commit the changes

git commit -m "Added a new paragraph to index.html"

Step 5: Push to GitHub

git push

(You don't need -u origin main anymore - Git remembers!)

Step 6: Verify on GitHub

Refresh your GitHub repository page and click on index.html - you'll see your new changes!

You now know the complete workflow: Create → Add → Commit → Push! 🚀

Quick Summary: The Git Workflow

Every time you want to save and upload your work:

  1. git add . - Stage your changes
  2. git commit -m "description of changes" - Save a snapshot
  3. git push - Upload to GitHub

Remember this pattern - you'll use it constantly!

Part 5: Cloning an Existing Repository

Cloning means downloading a copy of a repository from GitHub to your computer.

Method 1: Cloning Your Own Repository

Step 1: Get the repository URL

  • Go to your repository on GitHub
  • Click the green "Code" button
  • You'll see a URL like: https://github.com/yourusername/my-first-project.git
  • Click the copy icon (📋) next to the URL

Step 2: Choose where to save it on your computer

  • Open your terminal/command prompt
  • Navigate to where you want to save the project

For example, to save it in your Documents folder:

Windows:

cd Documents

Mac/Linux:

cd ~/Documents

Press Enter

Step 3: Clone the repository

Type git clone followed by the URL you copied:

git clone https://github.com/yourusername/my-first-project.git

Press Enter

You'll see output like:

Cloning into 'my-first-project'...
remote: Enumerating objects: 3, done.
remote: Counting objects: 100% (3/3), done.
remote: Total 3 (delta 0), reused 0 (delta 0)
Unpacking objects: 100% (3/3), done.

Step 4: Enter the project folder

cd my-first-project

Press Enter

Step 5: Verify you have the files

Type:

ls

(On Windows, you might need to type dir instead)

Press Enter

You should see the README.md file listed.

Success! You've cloned your repository to your computer.

Method 2: Cloning Someone Else's Repository

Let's practice by cloning a real repository.

Step 1: Find a repository to clone

  • Open your web browser
  • Go to: github.com/octocat/Hello-World
  • This is GitHub's example repository

Step 2: Copy the repository URL

  • Click the green "Code" button
  • Copy the URL: https://github.com/octocat/Hello-World.git

Step 3: Open terminal and navigate to where you want to save it

cd Documents

Step 4: Clone the repository

git clone https://github.com/octocat/Hello-World.git

Press Enter

Step 5: Enter the folder

cd Hello-World

Step 6: Look at the files

ls

(or dir on Windows)

Success! You've cloned someone else's repository.

Understanding What Just Happened

What is Git?

Git is a tool that runs on your computer. It tracks changes to your files, like a super-powered "undo" button that remembers everything.

What is GitHub?

GitHub is a website where you can store your Git projects online. It's like Google Drive or Dropbox, but specifically for code.

What is a Repository?

A repository is a project folder that Git watches. It remembers every change you make to files inside it.

What is Cloning?

Cloning is making a copy of a repository from GitHub onto your computer. You get all the files and all the history of changes.

Common Problems and Solutions

Problem 1: "git: command not found"

Solution: Git isn't installed correctly. Go back to Part 1 and reinstall.

Problem 2: "Permission denied"

Solution: You might be trying to clone into a protected folder. Try cloning to your Documents folder instead.

Problem 3: Can't find the cloned folder

Solution: Check which folder you were in when you ran the clone command. Use pwd (Mac/Linux) or cd (Windows) to see your current location.

Problem 4: "fatal: repository not found"

Solution: Check that you copied the URL correctly. Make sure there are no extra spaces.

Problem 5: GitHub asks for username and password repeatedly

Solution: This is normal for HTTPS cloning. Later, you can learn about SSH keys which make this easier.

Tips for Beginners

  1. Don't worry about making mistakes - You can always delete a repository and start over
  2. Practice often - Create repositories and clone them until it feels natural
  3. Read the messages - Git and GitHub show helpful messages when something goes wrong
  4. Start simple - Don't try to learn everything at once
  5. Take notes - Write down the commands you use most often
  6. Ask for help - The developer community is friendly to beginners
